- 状态：done（实现与自动化验证完成；Windows 人工验收通过；macOS/Linux 不在当前范围）
- 任务：

- [x] 后端窗口管理：每显示器一个无边框/透明/置顶/跨工作区窗口；提示条不可聚焦，激活 Popup 休息切换为完整输入阻断层（A8/A9 修复，ADR-0007）。
- [x] 前端复刻休息窗（倒计时、进度、结束/推迟/跳过）。
- [x] 手动结束与自然结束统一走结束流程，广播关闭所有休息窗。

- 验收：SPEC-0002 实现与自动化验证通过，Windows 多显示器/焦点/跨工作区/结束流程人工验收通过；SPEC-0003 核心触发/推迟/结束通过；SPEC-0009 播放通道、资源接入与 Windows 真实音频人工验收通过。macOS/Linux 平台差异移出当前范围。
