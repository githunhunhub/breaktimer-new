# ADR-0035：宣传页特性区改为共享悬停预览

- 状态：已接受
- 日期：2026-11-18
- 决策者：项目维护者

## 背景

上一版让四张特性卡各自带一张截图，卡片变成两行两列，与既有的一行四卡版式不一致；
同时各图原始比例不同，视觉大小不统一。用户还要求调整 Hero 标题并移除下载区的
SmartScreen 提示。

## 决策

1. 四张特性卡恢复一行等宽排列；卡片下方共用一块截图预览区，默认显示第一张。
2. 鼠标悬停或键盘聚焦某张卡时，通过 CSS 兄弟选择器切换到对应截图；点击卡片可跳转到
   预览区，触屏通过聚焦切换。不引入脚本。
3. 共享预览使用宽幅图片舞台，截图通过 `object-fit: cover` 以中心聚焦方式铺满舞台；
   原始 PNG 文件保持不变。该取舍优先保证界面内容足够大、四卡仍在一行，代价是截图边缘
   可能被裁切。
4. Hero 中文标题改为「给工作，留一点呼吸」，英文使用语义对应的
   `Give work room to breathe.`；下载区移除 SmartScreen 提示块，`README.md` 的安装说明不变。

## 理由

共享预览避免同一屏重复呈现四张大图，让一行四卡的扫描节奏更清晰；同尺寸画布解决原图
比例差异导致的视觉大小不一。纯 CSS 交互保持 SPEC-0016 的无脚本、纯静态约束；
`prefers-reduced-motion` 下关闭过渡。SmartScreen 说明放在下载区会分散下载入口注意力，
安装帮助已有 README 与 Releases 承载。

## 影响

- 部分取代 ADR-0034 的第 1、3 条；本地截图与 CSS-only 动画的总体约束继续保留。
- 浏览器不支持 `:is()` 时不会切换图片，但会保留第一张静态预览；现代 Chromium / Edge
  已支持该选择器。
- 截图内容或语言变化时需重新生成同尺寸画布素材并同步中英文页面。
