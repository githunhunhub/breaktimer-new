# ADR-0034：宣传页使用本地应用截图与 CSS 动画

- 状态：已接受
- 日期：2026-11-18
- 决策者：项目维护者

## 背景

宣传页特性区需要展示应用实际界面与轻量动画，同时必须保持纯静态、无脚本、无远程
资源；Hero 的轨道标签也需要跟随四张特性卡调整，避免继续展示过时的功能名称。

## 决策

1. 四张特性卡各放一张由本地运行应用生成的界面截图，放在 `site/assets/screenshots/`；
   中文与英文页面分别使用对应语言的界面。
2. 截图只截取应用窗口自身，包含少量窗口边框以表明是桌面应用；不合成系统托盘或
   Windows 通知，因为它们不是可直接截图的页面元素。
3. 动画只使用 CSS：Hero 轨道缓慢旋转、特性卡进入视口时轻微揭示、卡片悬停时小幅
   位移；`prefers-reduced-motion: reduce` 下关闭动画。

## 理由

真实界面能让访问者快速确认产品形态与当前能力；本地 PNG 与 CSS 不会破坏
SPEC-0016 的静态站点约束，也不需要引入 JavaScript 观察器或第三方动画库。
CSS 伪元素与 `:target` 不能兼顾自动触发和键盘可访问性，因此滚动揭示采用
`animation-timeline: view()` 并在不支持该特性的浏览器中自然降级为静态展示。

## 影响

- `site/scripts/check-static.mjs` 继续检查所有本地图片引用。
- 新增截图是构建产物式素材，需要纳入 Git；应用界面或文案变化后应重新截取。
- 动画不能在无脚本站点上按视口精确重播所有效果；浏览器不支持 `view()` 时只显示静图。
