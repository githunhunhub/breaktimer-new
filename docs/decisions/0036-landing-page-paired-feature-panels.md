# ADR-0036：宣传页功能区改为图文成对切换

- 状态：已接受
- 日期：2026-11-18
- 决策者：项目维护者

## 背景

共享截图预览方案容易出现功能列表与下方截图脱节：切换列表后截图仍停留在第一项。
用户确认图文必须成对出现，同时希望图片更大、更完整，说明文字更小，圆角与页面风格统一。

## 决策

1. 功能区使用四个顶部标签；每个标签对应一个独立面板，面板内同时包含原功能说明和对应
   截图，切换后不会错位。
2. 截图以用户提供的原图为依据，统一生成为 `1280×800` 透明 PNG：原图等比缩放居中，
   实际截图内容裁切为 `12px` 圆角，接近应用窗口自身圆角；页面按可用宽度等比放大。桌面端左侧说明、右侧截图且
   图片占比大于说明栏，移动端说明在上、截图在下。
3. 标签支持点击、键盘聚焦与悬停切换；页面内唯一一段脚本负责同步标签状态与面板显隐，
   不加载远程脚本。
4. 用细分隔线与轻网格背景承载功能区，不再给每组图文套独立卡片或阴影框。

## 理由

把说明与图片放进同一个面板可以从结构上保证对应关系；独立面板无需靠 CSS 兄弟选择器
同步多个区域，行为更稳定。放大图片并把说明栏收窄，符合用户对该区域视觉重心的要求。
对图片内容直接做圆角裁切，避免非满幅截图的留白画布显示出错误轮廓。

## 影响

- 取代 ADR-0035 的共享悬停预览方案；本地截图与纯静态约束保持不变，静态检查禁止带 `src` 的脚本。
- 页面 HTML 会包含四个面板，非当前面板使用 `hidden`，对无脚本环境仍可退化为第一项静态展示。
- 应用截图或功能说明变化时，需要同步更新对应面板内容。
