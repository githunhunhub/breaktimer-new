# SPEC-0024：NSIS 安装器多语言

- 状态：in-progress
- 日期：2026-11-16
- 关联：SPEC-0011 · SPEC-0014 · `app/src-tauri/tauri.conf.json`

## 背景 / 问题

当前 NSIS 安装器只包含英语界面。简体中文用户在安装、维护和卸载应用时仍会看到英文，
与应用运行时的中英文支持不一致。

Tauri v2 会根据 NSIS `languages` 列表自动选择当前系统语言；系统语言不在列表中时使用列表
首项。因此可以通过固定受支持语言及其顺序，在不增加自定义安装器界面的前提下实现系统语言
优先和英语回退。

## 需求（做什么）

1. NSIS 安装器、维护界面和卸载器支持英语与简体中文。
2. 安装器默认使用系统语言，不显示额外的语言选择对话框。
3. 系统语言为英语或简体中文时，使用对应语言。
4. 系统语言不受支持或无法匹配时，回退到英语。
5. 安装器的语言支持与应用现有 `en-US`、`zh-CN` 两种界面语言保持一致。
6. 安装器欢迎页只要求用户退出正在运行的 BreakTimer-new。

## 验收标准（可测）

- [x] **I1** NSIS 配置包含 `English` 与 `SimpChinese`，且 `English` 位于首位。
- [x] **I2** NSIS 配置关闭语言选择对话框，由安装器自动读取系统语言。
- [x] **I3** Tauri 配置通过 schema 校验与完整 `pnpm verify`。
- [ ] **I4** 未显式打包时不生成安装包；后续打包验证时，英文与简体中文系统分别显示对应
      安装器语言，不支持的系统语言显示英语。
- [x] **I5** 英语与简体中文均使用自定义 NSIS 语言文件，并保留 Tauri 安装器所需的全部
      自定义消息。
- [x] **I6** 英语与简体中文欢迎页均只要求退出正在运行的 BreakTimer-new，不包含关闭
      其他程序或重启计算机的说明。

## 非目标 / 边界

- 不为安装器新增应用未支持的第三种语言。
- 不提供安装过程中的手动语言切换入口。
- 不修改应用运行时语言解析、设置页语言选择或共享翻译资源。
- 不改变 NSIS 安装模式、图标、产品名、应用标识或安装/卸载流程。

## 设计要点（可选）

- 在 `bundle.windows.nsis` 中配置
  `languages: ["English", "SimpChinese"]` 与 `displayLanguageSelector: false`。
- 语言顺序表达回退优先级：首项 `English` 是系统语言无法匹配时的最终回退语言。
- NSIS 默认欢迎页文案不适用于当前安装流程，通过 `customLanguageFiles` 覆盖英语与简体中文
  欢迎页文案。
- 自定义语言文件会替换 Tauri 内置的对应语言文件，因此必须同时保留全部 Tauri 自定义安装
  消息，避免维护与卸载流程出现缺失文案。
