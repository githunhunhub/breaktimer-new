# SPEC-0016：宣传页（Landing Page）

- 状态：draft
- 日期：2026-11-02
- 关联：SPEC-0011 · SPEC-0012 · ADR-0011 · 视觉参考 <https://breaktimer.app/>

## 背景 / 问题

BreakTimer-new 目前对外只有 GitHub 仓库和 `README.md`：拿到链接的人要先读一整页 Markdown
才知道它是什么；GitHub Releases 页面也没有引导未签名安装包的 SmartScreen 处置方式。

2026-11-02 用户提出做一个单页宣传页，版式参考旧版项目官网 <https://breaktimer.app/>，
计划托管到 GitHub Pages 或 Cloudflare Pages。仓库已公开（`githunhunhub/breaktimer-new`），
但还没有任何站点，这个页面会成为项目的第一个对外门面。

## 需求（做什么）

1. 单页静态宣传页，信息层级对齐参考站：顶栏 → Hero → 特性区 → 与旧版的关系 → 下载区 → 页脚。
2. 内容只描述当前已实现的能力（SPEC-0002 ~ SPEC-0014），不承诺 macOS/Linux、自动更新、
   企业部署或任何尚未实现的特性。
3. 下载区只指向 GitHub Releases 的最新安装版（`*-setup.exe`）与便携版（`*-portable.zip`），
   并明确写出未签名安装包在 SmartScreen 下的处置（「更多信息」→「仍要运行」），
   措辞与 `README.md` 保持一致。
4. 说明与旧版 BreakTimer 的关系：独立重写、不迁移旧设置、可与旧版共存（源自
   `tom-james-watson/breaktimer-app`）。
5. 纯静态实现：资源全部本地，不引远程字体与 CDN，无第三方统计、无 Cookie、无表单。
6. 站点目录独立于 `app/`（应用代码）与 `docs/`（Markdown 事实源），发布产物只有站点目录。
7. 托管在 GitHub Pages 或 Cloudflare Pages，二者取其一或都配，见「开放问题」Q2。
8. 语言按 Q4 定；首版至少提供简体中文。

## 验收标准（可测）

- [ ] **L1** 本地静态服务器下页面可用，1440px 与 375px 两个宽度下无横向滚动、无元素重叠。
- [ ] **L2** 下载区每个链接都可点开并返回 200，目标为 GitHub Releases 或其中资产。
- [ ] **L3** 页面文案逐条对照 `README.md`「主要功能」，不出现 README 与 spec 之外的能力描述。
- [ ] **L4** 断网后刷新（外链除外）样式与图片完整，证明无远程字体 / CDN 依赖。
- [ ] **L5** 按子路径（模拟 `/breaktimer-new/`）部署后所有资源返回 200。
- [ ] **L6** 桌面 Lighthouse 的 Performance / Accessibility / Best Practices / SEO 均 ≥ 90，
      结果随验收记录提交。
- [ ] **L7** 上线后站点地址、HTTPS 证书与 404 行为均符合预期。
- [ ] **L8** 发布 workflow 只发布站点目录，不构建、不改写 `app/` 产物，不触碰发布流水线（SPEC-0015）。
- [ ] **L9** `app/` 全部门禁保持通过（`pnpm format:check` / `lint` / `typecheck` / `test` / `build`
      与 cargo 的 `fmt --check` / `check` / `test`）。

## 非目标 / 边界

- 不做文档站、博客或更新日志页；变更日志继续由 GitHub Release 与 `git-cliff` 承担。
- 不自行托管安装包，不做下载镜像；产物只经 GitHub Releases 发布。
- 不做在线试用、Web 版或内嵌演示播放器。
- 不复制参考站的文案、图片与字体文件：旧站内容为 GPLv3，本项目当前没有 `LICENSE`（见 Q6）。
- 不修改 `app/` 运行代码，不改变发布流水线语义，只新增独立的站点发布配置。

## 设计要点

参考站实测结构（2026-11-02 抓取）：单页，顶栏 logo → Hero（一句话 + 两个按钮 + 产品截图）
→ 四张等宽特性卡 → 按平台列包的下载区 → 页脚（资源链接 + 许可证 + 免责声明）。对应到本项目：

| 区块     | 内容                                                      | 素材                  |
| -------- | --------------------------------------------------------- | --------------------- |
| 顶栏     | 名称 + 锚点导航（功能 / 下载 / 关于）                     | `app/public/icon.png` |
| Hero     | 一句话价值 + 「下载」+「GitHub」两个按钮                  | 图标 + 应用截图（Q5） |
| 特性     | 四张卡：休息调度 / 全屏阻断与通知 / 托盘与自启 / 中英双语 | 截图（Q5）            |
| 关系说明 | 独立重写、不迁移旧数据、可与旧版共存                      | 无                    |
| 下载     | 安装版 / 便携版两个入口 + SmartScreen 说明                | 无                    |
| 页脚     | 仓库 / Releases / 源自 BreakTimer 的署名 / 许可声明（Q6） | 无                    |
