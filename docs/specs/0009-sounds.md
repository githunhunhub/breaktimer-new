# SPEC-0009：声音

- 状态：confirmed
- 日期：2026-10-13
- 关联：ADR-0002 · SPEC-0002 · SPEC-0008 · 旧实现 `breaktimer-app/app/main/lib/ipc.ts`、`types/settings.ts`

## 背景 / 问题

休息开始/结束时的提示音是重要的用户反馈。旧版提供多种声音类型与音量调节，声音可关闭。

## 需求（做什么）

1. 提供声音类型 `SoundType`：None / Gong / Blip / Bloop / Ping / Scifi。
2. 提供音量 `breakSoundVolume`（0–1）。
3. 休息开始时依设置播放开始提示音；结束休息时（主窗口触发）依设置播放结束提示音。
4. `SoundType=None` 时不播放任何声音。

## 验收标准（可测）

- [ ] 选择非 None 声音类型时，休息开始播放对应提示音。
- [ ] 结束休息时播放结束提示音（若声音类型非 None）。
- [ ] 音量可调并生效（0–1）。
- [ ] 选择 None 时不播放声音。

## 非目标 / 边界

- 不做自定义音频文件上传。
- 不做音频混音/淡入淡出等高级音效处理。

## 设计要点（可选）

- 复刻旧版的「隐藏声音播放通道」思路；具体用前端 audio 或 Rust 音频库在实现时定，选择结果记 ADR（若构成取舍）。

## 实现计划

- [ ] 实现声音播放通道与声音资源。
- [ ] 在休息开始/结束流程中接入播放命令。
