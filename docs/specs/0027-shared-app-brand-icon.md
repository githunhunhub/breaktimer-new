# SPEC-0027：统一应用与宣传页品牌图标

- 状态：done
- 日期：2026-11-19
- 关联：SPEC-0011 · SPEC-0016 · SPEC-0020 · ADR-0037

## 背景 / 问题

应用、网站与 README 当前使用各自保存的旧版位图图标，存在多份来源不一的副本。
用户要求把这些对外展示位置统一换成 `breaktimer-app/resources/src/icon.svg` 所表示的图形。
旧源码目录只读，项目需要把图形源纳入新版应用与网站的资产链路，并保证托盘、窗口、
安装包以及静态站点仍使用平台可接受的格式。

## 需求（做什么）

1. 应用与宣传页对外展示的品牌图形统一使用指定 SVG 的设计，不允许各位置继续使用旧位图设计。
2. 指定 SVG 的旧源码文件保持只读；在新版仓库保存可复现的图标源，并据此生成所需位图资源。
3. 桌面应用覆盖系统托盘、应用窗口、窗口 favicon、NSIS 安装器与卸载器图标，以及现有 Windows
   图标集；宣传页覆盖中英文页面的品牌区、Hero、favicon、Apple touch icon 与 OG 分享图。
4. README 顶部展示图使用同一图形。
5. 静态站点继续保持纯静态、本地资源与子路径部署约束；平台不接受 SVG 的位置使用由同一 SVG
   导出的 PNG。

## 非目标 / 边界

- 不修改旧源码目录中的任何文件。
- 不改变产品名称、应用标识、版本号、站点文案或下载流程。
- 不执行 `tauri:build`、`portable:build`、bundle 等打包命令。
- 不替换功能截图中的应用界面，只替换品牌图标及图标生成源。
- 不为当前 Windows-only 发布范围新增或删除平台图标尺寸。

## 设计要点

- 在新版 `app/assets/logo.svg` 保存指定图形，作为应用与站点共享的来源；旧源码仅作为初始复制来源。
- Web 页面直接用 `logo.svg` 展示品牌图形；favicon、Apple touch icon、OG 分享图与原生图标由同一
  SVG 栅格化，避免各平台 SVG 支持差异。
- Windows 安装器与 macOS 兼容图标继续消费已有 `icon.ico` / `icon.icns`，在各自资源容器内替换
  图像项，保留多尺寸与跨平台兼容性。
- Tauri 继续读取既有文件名与尺寸，只替换文件内容，不改动 `tauri.conf.json` 的 bundle 图标路径。
- 托盘图标继续读取 `icons/32x32.png`，只替换该资源内容。
- 在站点维护说明与相关 SPEC 中记录新源文件和重建方式，方便跨设备复现。
