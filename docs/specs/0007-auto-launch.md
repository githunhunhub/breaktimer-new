# SPEC-0007：自启动

- 状态：confirmed
- 日期：2026-10-13
- 关联：ADR-0002 · 旧实现 `breaktimer-app/app/main/lib/auto-launch.ts`

## 背景 / 问题

BreakTimer 默认随系统登录自启动，保证用户不主动打开也能持续提醒。重构后需要等价能力。

## 需求（做什么）

1. 支持设置项 `autoLaunch`，默认开启。
2. 开启时注册系统自启动；关闭时取消注册。
3. 开发环境不触发真实的自启动注册（避免污染开发机）。

## 验收标准（可测）

- [ ] 开启后，用户登录系统时应用自动启动。
- [ ] 关闭后，登录系统时不再自动启动。
- [ ] 打包运行时注册的是发布产物路径；开发环境不注册。

## 非目标 / 边界

- 不做「开机自启 + 最小化到托盘」之外的启动行为定制。
- 不做跨平台注册表/plist 手工实现（优先用 Tauri 官方 autostart 插件）。

## 设计要点（可选）

- 使用 Tauri 官方 autostart 插件，避免手工处理 Windows 注册表、macOS LaunchAgent、Linux autostart 文件。

## 实现计划

- [ ] 接入 Tauri autostart 插件。
- [ ] 设置窗口提供自启动开关，并在切换时调用后端。
