# SPEC-0021：圆形休息卡（环形进度）

- 状态：in-progress
- 实现状态：代码与自动化验证完成；默认保持矩形。已按首轮人工验收反馈调整圆直径与防裁切布局，等待复验
- 日期：2026-11-13
- 关联：SPEC-0002 · SPEC-0010 · SPEC-0014 · ADR-0004 · ADR-0007 · ADR-0027 · ADR-0028 · 代码 `components/break/`、`components/settings/`、`state/settings.rs`

## 背景 / 问题

现有 Popup 休息阶段的休息卡是矩形：`rounded-lg`、`max-w-[500px]`、`min-h-[300px]`，
进度用底部横向进度条表示。用户希望在保留方形之外新增圆形样式。
2026-11-13 用对话内效果图对比了三个圆形方向（环形进度 / 扇形填充 / 轨道光点），
用户确认采用「环形进度」：正圆盘 + 圆环描边进度 + 圆内居中内容。
效果图属过程参考，视觉与行为规格以本文件为准。

## 需求（做什么）

1. 休息卡新增「圆形」样式：正圆、在显示器中居中；进度以圆环描边呈现，
   从 12 点方向顺时针增长，进度到 100% 时圆环闭合。
2. 圆内自上而下包含：休息标题、`mm:ss` 倒计时、休息文案（多行）、
   `Cancel Break` 按钮（`endBreakEnabled=false` 时不显示）。
3. 圆形卡沿用现有主题设置：`backgroundColor`、`textColor` 同时作用于圆盘、
   进度环、文字与按钮；`showBackdrop` / `backdropOpacity` 语义不变。
4. 提供形状切换：设置中新增「休息卡形状」（矩形 / 圆形），持久化到现有设置模型；
   默认矩形（保持现有行为），保存后从下一次休息生效，切回矩形时现有外观与交互不变。
   当前休息周期内不即时切换形状；语言即时切换仍按 SPEC-0014 执行。
5. 自定义标题与文案沿用 `breakTitle` / `breakMessage`，文案资源走
   `app/locales/`（SPEC-0014），中英双语都要能完整显示。
6. 只改变「休息卡」的渲染，不改变覆盖窗几何、焦点策略与输入阻断
   （SPEC-0002、ADR-0004、ADR-0007）。休息前提示条保持矩形。

## Windows 人工验收步骤

> 在 Windows 真机用 `pnpm tauri:dev` 启动后执行；本轮不打包。

1. **默认 / 持久化**：新配置不改动形状时触发休息，确认仍为矩形；在
   「设置 → 自定义 → 休息卡形状」选择「圆形」并保存，触发休息确认圆形；退出并重启应用，
   再触发休息确认仍为圆形；切回「矩形」保存并触发休息，确认恢复原矩形外观与横向进度条。
2. **圆环与文案**：观察圆环从 12 点顺时针增长、在结束前接近闭合；确认圆内标题、
   `mm:ss`、多行文案和「取消休息」均可见且不重叠。分别用中英文默认文案和一段很长的自定义
   文案复验，确认不裁切、不溢出，需要时正文可滚动。
3. **主题与遮罩**：修改 `backgroundColor` / `textColor` 并保存，确认圆盘、进度环、文字和按钮
   同步变色；分别开关视觉遮罩并调整透明度，确认只影响遮罩，窗口仍覆盖完整显示器。
4. **交互回归**：将 `endBreakEnabled=false` 后触发休息，确认圆形卡不显示「取消休息」且没有
   其它提前结束入口；按钮可用时点击「取消休息」，确认所有显示器休息窗同时关闭。观察休息前
   60 秒提示条仍为矩形，开始 / 推迟 / 跳过行为不变。
5. **多显示器 / DPI**：在双显示器或不同缩放比例下触发休息，确认每个显示器都有一个正圆居中、
   进度同步、覆盖任务栏 / 托盘区域且底层不能通过鼠标绕过；在较窄显示器或高 DPI 下复验文案与
   按钮不重叠圆环。
6. **下一次休息生效**：先触发休息，确认当前休息窗形状与倒计时；待本次休息结束后从托盘打开设置，
   切换形状并保存，再触发下一次休息，确认新形状生效且倒计时从新的休息周期开始；当前休息周期内
   不要求即时变形。切换语言保存后确认设置页即时切换，并在下一次休息窗确认文案已更新。

## 非目标 / 边界

- 不改窗口几何、焦点策略、输入阻断或调度器、声音、托盘、通知模式。
- 不实现被淘汰的「扇形填充」「轨道光点」方案，不做形状切换动画。
- 不提供圆盘直径、圆环粗细等用户可调参数（先用固定自适应值）。
- `Notification` 模式无休息卡，不涉及。
- 当前里程碑只验收 Windows；不把结果外推到 macOS/Linux。

## 设计要点（可选）

- 圆环用归一化 `viewBox` 的 SVG `circle` + `stroke-dasharray` / `stroke-dashoffset`，
  从 -90° 起，避免把半径写死成像素。
- 圆直径取 `min(58vmin, 440px)`：与 500×300 的矩形卡等面积（≈437px），
  两种形状视觉重量一致，窄窗口下也不会撑满整块屏幕。
- 圆内内容区限制在直径的 76% × 62% 内（即内接正方形范围内），并按「绝对定位 + 位移」
  真正垂直居中；因此标题与「取消休息」不会落到圆弧内收的边缘上。
- 圆内排版用相对单位（容器查询单位 `cqw` / `clamp`）随直径缩放：标题最多两行截断，
  `mm:ss` 单独放大，正文超长时在自身区域滚动，错误提示也限制高度可滚动，保证长文案可读且不溢出。
- 环形进度对外暴露 `role="progressbar"`、`aria-valuemin/max/now` 与本地化的
  `break.progressLabel`，屏幕阅读器可读到同一份进度值；轨道与进度都用 `currentColor`，
  仅以透明度区分，切换 `textColor` 时整卡同步变色。
- 形状作为 `Settings` 的枚举字段持久化，Rust 与 TypeScript 双份镜像、camelCase 序列化、
  缺失字段回退默认值（沿用 SPEC-0010 的加载语义）；默认值取矩形，避免未经确认改变现有默认外观。
- 设置项放在「自定义」页签，靠近主题 / 遮罩相关卡片；新增文案键同步中英 locale。
- 形状保存不新增跨窗口事件，也不改变 `break-status`、调度器状态或当前休息倒计时；
  休息窗沿用既有 `get_settings` 加载语义，新形状从下一次休息生效。语言仍由
  `locale-changed` 即时刷新（SPEC-0014）。
- 形状字段取舍见 ADR-0027；「下一次休息生效 / 不即时刷新」见 ADR-0028（部分取代 ADR-0027）。
- 圆内正文使用可滚动的自适应区域，长文案不裁切、不覆盖圆环与按钮；圆环底色与进度色
  都跟随 `textColor`，通过透明度区分轨道与进度。
- 效果图仅为过程参考；若实现与本文冲突，以本文为准并同步修正。
