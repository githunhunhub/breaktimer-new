# SPEC-0004：工作时段

- 状态：confirmed
- 日期：2026-10-13
- 关联：ADR-0002 · SPEC-0003 · 旧实现 `breaktimer-app/app/main/lib/breaks.ts`

## 背景 / 问题

用户只希望在工作时段被提醒休息，非工作时段静默。旧版按「每周七天各自可启用、每天支持多个时间段」建模。

## 需求（做什么）

1. 支持全局开关 `workingHoursEnabled`。
2. 每周七天（周一至周日）各自可独立启用/关闭；启用时可配置一个或多个时间段（`fromMinutes`/`toMinutes`）。
3. 当前时间落在任意启用日的任一时间段内，视为「在工作时段」。
4. 非工作时段不触发休息；进入工作时段时重置「距上次休息」。

## 验收标准（可测）

- [ ] 关闭 `workingHoursEnabled` 时，任何时间都视为可休息。
- [ ] 某天关闭时，该天不触发休息。
- [ ] 某天启用且有多个时间段时，任一命中即视为在工作时段（含跨时段边界）。
- [ ] 从「非工作时段」进入「工作时段」时重置「距上次休息」。

## 非目标 / 边界

- 不做节假日/法定假日日历。
- 不做跨天时间段（`toMinutes` 小于 `fromMinutes` 的隔夜区间，旧版不支持）。

## 设计要点（可选）

- 时间一律用「当天分钟数」（0–1439）表达，与旧版 `WorkingHoursRange` 一致，避免时区/日期对象复杂度。
