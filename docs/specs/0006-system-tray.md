## 背景 / 问题

BreakTimer 常驻系统托盘，用户无需打开窗口即可看到下一次休息时间、临时禁用、立即休息或退出。托盘是桌面应用的核心入口之一。

## 需求（做什么）

1. 常驻系统托盘图标。
2. 托盘菜单按状态动态显隐：
   - 「Next break in …」（禁用项，展示剩余时间）；
   - 「Disabled for …」（临时禁用时）；
   - 「Outside of working hours」（非工作时段）；
   - 「Idle」（闲置时）；
   - 「Enable」（禁用时）/「Disable…」子菜单（Indefinitely、30 分钟、1 小时、2 小时、4 小时、Rest of day）；
   - 「Start break now」（未在休息时）；
   - 「Settings…」「About…」「Quit」。
3. 临时禁用到期后自动重新启用。
4. macOS 托盘标题展示「距下次休息 / 距上次休息」文本（`TrayTextMode`）；Windows 左键弹出菜单。
5. Popup 休息激活期间，托盘被覆盖窗遮挡且不能接收鼠标点击；用户必须先点 `Cancel Break`
   结束休息，才能再次操作托盘。

## 验收标准（可测）

> 快照生成、菜单文案、禁用时长换算与 macOS 标题模式已有单元测试覆盖；下列条目均需在真实桌面运行验收。

- [ ] 托盘图标常驻，退出应用前不消失。
- [ ] 菜单项按状态正确显隐（休息中/禁用/非工作时段/闲置各态）。
- [ ] 「Disable…」选择 30 分钟后禁用，30 分钟后自动恢复启用。
- [ ] 「Start break now」立即触发休息；Popup 模式完整覆盖所有显示器，Notification 模式只发系统通知。
- [ ] Popup 休息期间任务栏和托盘不可点击；`Cancel Break` 后托盘菜单恢复为可操作。
- [ ] 「Settings…」打开设置窗口；「Quit」退出应用。
- [ ] macOS 下托盘标题按 `TrayTextMode` 更新；Windows 下左键弹出菜单。

## 非目标 / 边界

- 不实现跨平台的托盘图标自定义绘制（沿用现有图标资源）。
- 不覆盖设置窗口本身（见 SPEC-0010）。
- 不在 Popup 休息期间提供托盘逃生入口；系统级快捷键仍不属于应用输入阻断范围（ADR-0007）。

## 设计要点（可选）

- 托盘菜单与调度状态共用后端状态；菜单刷新沿用旧版 5s 轮询思路，必要时改为事件驱动。
- Linux/GNOME 无原生托盘时，沿用旧版「重开设置窗口」的降级策略。
