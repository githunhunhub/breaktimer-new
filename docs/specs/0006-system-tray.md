## 背景 / 问题

BreakTimer 常驻系统托盘，用户无需打开窗口即可看到下一次休息时间、临时禁用、立即休息或退出。托盘是桌面应用的核心入口之一。

## 需求（做什么）

1. 常驻系统托盘图标。
2. 托盘菜单按状态动态显隐：
   - 「Next break in …」（禁用项，展示剩余时间）；
   - 「Disabled for …」（临时禁用时）；
   - 「Outside of working hours」（非工作时段）；
   - 「Idle」（闲置时）；
   - 「Enable」（禁用时）/「Disable…」子菜单（Indefinitely、30 分钟、1 小时、2 小时、4 小时、Rest of day）；
   - 「Start break now」（未在休息时）；
   - 「Settings…」「About…」「Quit」。
3. 临时禁用到期后自动重新启用。
4. Windows 左键弹出菜单；macOS 托盘标题实现保留，但当前里程碑不包含 macOS 验收。
   `Menu Bar Text` 是 macOS-only 能力，Windows 设置窗口不得展示该控件。
5. Popup 休息激活期间，托盘被覆盖窗遮挡且不能接收鼠标点击；用户必须先点 `Cancel Break`
   结束休息，才能再次操作托盘。
6. 点击托盘 `Settings...` 时，设置窗口无论处于隐藏、最小化还是失焦状态，都必须恢复并聚焦。
7. 托盘菜单打开后保持可见，直到用户选择菜单项或主动关闭；刷新托盘状态不得让已打开菜单消失。
8. 菜单关闭后不得遗留白点或其他视觉残影。

## 非目标 / 边界

- 不实现跨平台的托盘图标自定义绘制（沿用现有图标资源）。
- 不覆盖设置窗口本身（见 SPEC-0010）。
- 不在 Popup 休息期间提供托盘逃生入口；系统级快捷键仍不属于应用输入阻断范围（ADR-0007）。

## 设计要点（可选）

- 托盘菜单与调度状态共用后端状态；根菜单只绑定一次，后续在原菜单上更新文本与动态项，
  避免替换 Windows 正在显示的原生 `HMENU`（ADR-0010）。
- Linux/GNOME 无原生托盘时，沿用旧版「重开设置窗口」的降级策略。
