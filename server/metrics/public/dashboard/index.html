DATA NOTES

口径与延迟

  • 统计单位是独立客户端实例，不是自然人；一人多机或复制便携数据目录会影响估计。
  • 数值由 HLL 近似计算，通常存在约 1～3% 的相对误差。
  • KV 最终一致最多延迟约 60 秒；公开响应还可复用最多 60 秒缓存，因此相对采集时间可能累计延迟约 2 分钟。
  • 客户端覆盖升级保留同一 ID，不会重复增加日活或新增；同一客户端可在不同日期出现在不同版本分布中。
  • 版本、渠道和系统分布不能相加当作总体活跃，公开概览使用逐日活跃和 HLL 并集新增。
