DATA NOTES

口径与延迟

  • 统计单位是“装机”，不是“用户”；一人多机或复制便携数据目录会影响估计。
  • 数值由 HLL 近似计算，通常存在约 1～3% 的相对误差。
  • KV 最终一致最多延迟约 60 秒；公开响应还可复用最多 60 秒缓存，因此相对采集时间可能累计延迟约 2 分钟。
  • 无法统计卸载，累计装机不是现存用户数。
  • 同一装机升级后可能同时出现在多个版本的活跃数据中，版本值不应相加当作总活跃。
