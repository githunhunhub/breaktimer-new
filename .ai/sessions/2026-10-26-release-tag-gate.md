# 2026-10-26 Tag 前置验收门禁

## 背景

`v0.1.1` 首次 Tag 推送后，GitHub Actions 因测试依赖本地 `github` remote 而失败。为恢复发布，
同一 Tag 被重新指向修复提交后再次推送，导致同一版本出现失败与成功两轮 Actions 记录。

## 决定

- 后续 Tag 必须等待自动化检查和人工验收全部通过后再创建。
- 已推送到 GitHub 的 Tag 视为不可变，不删除、移动或覆盖。
- GitHub Actions 或 Release 发布失败时，修复后使用下一个 patch 版本重新发布。

## 落点

- 更新 SPEC-0015 需求、验收项 R15、设计要点、实现计划和变更记录。
- 更新 DEVELOPMENT.md 的打包与发布规则。
- 更新 PLAN-0004 风险、验证记录和变更记录。

## 验证

- 本次仅修改文档，不创建 Tag，不触发 Actions，不修改发布脚本。
- 下一次正式 Tag 时验证 R15。
